WASTE X UBOT - ENVIRONMENT SETUP

Required for Render/Railway:
API_ID       = Telegram API ID from my.telegram.org -> API development tools
API_HASH     = Telegram API HASH from my.telegram.org -> API development tools
BOT_TOKEN    = BotFather token for the host bot
OWNER_ID     = Telegram numeric user ID of the owner
SUDO_USERS   = Optional comma/space-separated numeric IDs allowed to use sudo commands
MONGO_URL    = MongoDB Atlas connection string (or another reachable MongoDB URI)
GROQ_API_KEY = Groq API key for .aichat and .vctalk transcription/AI

Optional:
GROQ_MODEL   = Groq chat model; default is openai/gpt-oss-20b
TTS_VOICE    = Edge TTS voice; default hi-IN-SwaraNeural
TTS_RATE     = Edge TTS rate; default -12%
TTS_PITCH    = Edge TTS pitch; default +5Hz
COOKIES_FILE = Path to cookies.txt if yt-dlp/YouTube requires cookies

IMPORTANT:
The connected account used by /add does NOT need STRING_SESSION1/2/... environment
variables. /add performs phone + OTP + optional 2FA login and stores the resulting
session in MongoDB. STRING_SESSION variables remain optional for preloaded accounts.

Commands added/fixed:
.vctalk on              -> all VCs currently joined by the connected ID; future joined VCs too
.vctalk off             -> all VC Talk disabled
.vctalk on <chat_id>    -> only that VC
.vctalk off <chat_id>   -> only that VC disabled
.aichat on / off        -> existing AI chat switch
.play <song>            -> connected ID joins current group's VC and plays the song
.autoplay on / off      -> related-song autoplay for that VC
.queue /skip /stop      -> music queue controls
.mmar on/off            -> own-message reactions
.omar on/off            -> target-user reactions

Build dependencies include edge-tts and ffmpeg is installed by the Dockerfile.
